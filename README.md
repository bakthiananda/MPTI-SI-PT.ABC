# Sistem Informasi PT. ABC
Sistem penggajian (dan subsistem terikat) mata kuliah MPTI

## Contribution Guideline
+ Buat branch baru untuk fitur yang ingin ditambah/ganti dengan subsistem
  tujuan, ex. `personalia-tambah-tabel-database`
+ Commit perubahan ke branch tersebut, lalu `push` ke branch dengan nama yang
  sama di repository Github
+ Buat pull request dengan deskripsi yang sesuai dengan perubahan yang dibuat,
  lalu minta min. 1 review untuk merge
